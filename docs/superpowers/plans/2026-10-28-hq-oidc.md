# HQ OIDC adapter implementation plan

> Agent execution: local TDD in this assigned subtask, with independent final review. No commits/pushes by this agent.

**Goal:** Add a deny-by-default, independently testable GitHub OIDC Request authorizer without wiring live activation.
**Architecture:** Pinned jose 6.2.13 validates signatures/registered claims; a bounded fixed-URL transport caches public keys only. Exact immutable repo identity and complete trust tuples map to fixed scope and hashed verified execution identity.
**Spec:** `docs/HQ_GITHUB_OIDC_DESIGN.md` (independently reviewed).
**Files:** `scripts/hq-oidc-auth.mjs`, `tests/hq-oidc-auth.test.mjs`; package/lock owned by core agent.

## Constraints and review focus

- All spec limits are enforced; no tokens/private keys persisted or printed. Only synthetic ephemeral RSA keys and stub fetch.
- Time validation accepts provider-shaped nbf-before-iat; expiry exact boundary denies.
- Configuration is copied/validated once; post-factory mutations do not relax it.
- Public key size/exponent/private-parameter bounds apply before import.
- Cache failures/timeout release the refresh guard without extending freshness; known fresh keys work during unknown-kid cooldown.
- No body consumption, credential forwarding, token-controlled URLs, shared pending I/O or default activation.
