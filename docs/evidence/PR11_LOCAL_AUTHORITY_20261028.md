State, event and receipt nonmutation are asserted for that expiry boundary. ## Limits and next gates
Production default authorization denies all requests. Injected synthetic identity is only a test fixture; its SQL helper endpoint must never be a deployment entrypoint. AWAITING_APPROVAL cannot exit via caller requests; DONE/merge authority is absent. Replayed claim receipts are historical outcomes, not evidence of an active lease. A new execution cannot replay another execution's key; cross-run unknown-outcome reconciliation remains future gated work.

This is local runtime evidence, not remote cross-Actions persistence, operational OIDC verification, a real coding engine, approved integration, or 24-hour E2E. Final combined local suite (state, planner and synthetic OIDC) passed 111 tests with no skips on Node v24.22.1, independently rerun during separate-agent code critique. Requested clock, identity-scope and final-time-check corrections were covered by regression tests. No formal GitHub approval, provider-attested reviewer identity or integrated product review is claimed. Exact published-revision CI remains pending publication. Account plan/cost, provisioning, live authentication permissions, retention and remote schema application remain separate approval gates.
