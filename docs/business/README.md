## 作業ルール

- ここは**公開リポジトリ**。私的な資産数・所在地、収支・顧客情報、資格証、未公開映像原本は保存しない。
- 価格・需要・見積・実際の購入・税引後手取りを区別し、推測を事実扱いしない。
- 市場調査は進んだが、**事業化・販売・収入の実証は0件**。候補を本命に固定しない。
- 商品設計は購入者・金額・全原価・安全・法令・継続率・本人時間を検証してから。
- GitHubに調査結果と失敗を追記する。大きな方針変更は本人の確認を経る。
